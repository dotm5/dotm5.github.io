当一张角色截图呈现出干净的明暗块、稳定的轮廓和局部高光时，直觉会把这些结果归到一个“角色材质”上。但在延迟渲染中，表面材质往往只负责生产一份 payload：颜色、法线、深度、区域信息和少量控制量。风格化明暗由后面的全屏阶段完成。

把 GBuffer 当成最终颜色，会导致两种错误：一是把中间编码误当成可直接显示的颜色，二是把某个通道的名字想当然地写成金属度、粗糙度或 AO。更合适的视角是把它看成一份跨阶段的数据合同。

![角色材质模块架构示意](./images/gbuffer-base-feature.png)

## 1. 一份 payload 至少包含四类信息

### 外观信息

Base Color、渐变输入、局部材质颜色通常属于外观层。它们不一定已经包含光照，尤其当后续阶段还需要根据光方向重新分档时。

### 几何信息

法线、深度、视图方向相关数据决定了后续阶段如何判断受光、边缘和遮挡。压缩法线需要先还原到统一空间，再进入 NPR 计算；编码后的两个颜色通道直接接到 Principled 的 Normal 输入是错误用法。

### 路由信息

区域 ID、材质角色、表面/轮廓类别等离散字段，作用更像“像素应该交给谁处理”：让同一个全屏阶段按像素选择不同的解释规则。

### 控制信息

头发投影、局部遮罩、边缘衰减、风格化阈值等内容，可能只占一个小通道或一部分数值范围。控制量的业务名称经常需要经过多次实验才能确定，公开重建时保留为可调参数。

## 2. 数据合同靠关系成立

在不同引擎或不同版本中，资源编号、通道排列和精度都可能变化。稳定的表达是：

~~~text
表面阶段写入
  {baseColor, normal, depth, role, control}
        ↓
区域路由
  选择通用光照或角色专用解释器
        ↓
风格化 Resolve
  根据 light / view / local masks 形成 Scene Color
~~~

这张关系图比“某个资源的某个通道永远是什么”更适合迁移。它说明了谁生产数据、谁消费数据、数据在哪个空间中有效，以及缺失时会损失什么。

## 3. 为什么同一部件可能被提交多次

多次提交不一定是重复绘制。一次可能写入表面 payload，另一次可能只写区域遮罩，第三次可能用同一几何生成独立轮廓或控制层。判断职责时，应比较：

- 是否写颜色、法线、深度或只写辅助目标；
- 深度读写和剔除方式是否变化；
- 使用的材质角色是否变化；
- 它影响的是几何覆盖，还是后续解释阶段的输入。

在 Blender 中，这些职责通常不应全部塞进一个材质节点树。表面颜色和法线留在 Shader Nodes；反壳轮廓放到 Geometry Nodes 或独立网格；需要屏幕空间信息的边缘处理放到合成器；诊断输出单独暴露。

## 4. 从多 MRT 转成显式语义

Blender Eevee 不需要复刻目标引擎的内部 MRT 布局。可以将它转换为：

| 运行时职责 | Blender 表达 |
| --- | --- |
| 基础颜色 | Base Color 与 Ramp 输入 |
| 法线编码 | Normal Map 或明确的向量还原节点 |
| 区域字段 | Color Attribute、Image Mask 或离散参数表 |
| 风格化控制量 | 命名的 Value/Color Socket |
| 角色深度 | Geometry/Layer 信息或合成器深度 |
| 轮廓类别 | 独立几何层、材质标记或 AOV |

这样做的好处是每个语义都能在视口里单独显示。若某个输入仍然未知，就让它进入 Diagnostic 模式并保持可见。

## 5. 常见错误

第一，把 GBuffer 颜色直接当作已经完成的 toon 颜色。这样会漏掉光照方向、局部灯和深度边缘。

第二，把区域字段当连续灰度。许多区域 ID 实际上是离散类别；直接插值会制造不存在的中间材质。

第三，为了“看起来更亮”把整个角色接到 Emission。它可能破坏光照能量、反射和间接光，甚至把角色当作场景发光源。

第四，用最后一张 Scene Color 反推每个中间通道。最终图是多个阶段的合成结果，不能代替中间输出。

## 6. 面向 Blender 的最小实现

先做一个 Shared Toon Core，输入统一的 Base Color、Normal、Light Direction、View Direction 和 Shadow/AO；再由 Face、Eye、Hair、Cloth 各自扩展局部输入。区域路由用显式 mask 表示，轮廓单独做几何层，最后再用合成器做非材质性的屏幕效果。

目标的复杂度没有降低，复杂度被放到了正确的层。只要每个模块的输入、输出和证据等级写清楚，后面可以逐步替换近似算法，而不用重写全部材质。
