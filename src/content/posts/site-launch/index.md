欢迎来到 **图形与创作笔记**。

这个博客用来长期整理我在 Blender、实时渲染、Shader、Unreal Engine、AI 与个人工具实验中的记录。首轮目标不是伪装成一个已经积累多年的站点，而是先建立一套可靠、可写、可搜索、可迁移的发布基础。

## 这里会记录什么

- Blender、Eevee / Cycles、NPR 与材质工作流
- 实时渲染、图形学和 Shader 分析
- Unreal Engine 渲染管线研究
- AI、Tokenizer、生成式工具与本地实验
- 个人项目、Notebook、技术复盘和作品展示

## 写作方式

我会尽量保留工具版本、关键参数、可复现步骤和失败路径。能够核验的事实、实验观察和个人判断会分开表达；当结论只适用于特定版本或硬件时，也会明确写出限制。

> [!NOTE]
> 站点目前处于初始化阶段。项目页和分类结构已经建立，真实内容会随着实验进度逐步补充。

## 当前状态

本站使用 Markdown 写作并生成完全静态的页面，搜索索引也在构建时生成。当前临时发布目标是 GitHub Pages；未来完成域名与备案准备后，同一份构建产物可以迁移到静态服务器。

如果你正在寻找具体主题，可以从[归档](/archive/)或[项目](/projects/)开始。
